Put diet_policy_engine.py and fdc_api_key.txt (your free USDA API key) in the same folder, open that folder in VS Code, and press the Run button on diet_policy_engine.py. When the menu appears, type a number and press Enter. Try option 6 first to load a sample meal plan, then option 4 to check it against all the diet policies and see what passes or fails. To use live USDA data, choose option 1, type a food name such as "chicken breast", pick a result, then choose a meal and enter the amount in grams. Repeat for each food, use option 2 to review your plan, and then option 3 or 4 to validate it. Type 0 to exit.
